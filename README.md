# Circle of Hope 💙

### An Online Support Community for Parents of Children with Autism

**Circle of Hope** is a web-based platform developed to support parents of children with autism by providing a space where they can connect with other families, communicate with specialists, share experiences, and receive guidance.

## ✨ Features

- **User Authentication:** Secure registration and login functionality.
- **Role-Based Access Control:** Three user roles: Parents, Specialists, and Administrators.
- **Parent Community:** Allows parents to share experiences and interact with other families.
- **Private Messaging:** Enables users to communicate privately.
- **Specialist Support:** Connects parents with specialists for guidance and support.
- **Admin Dashboard:** Allows administrators to manage users and posts and monitor platform activities.

## 🚀 Getting Started

### Prerequisites
- Node.js and npm
- MySQL
- Git

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Set up the database using the provided SQL file.

3. Configure your backend environment variables in a `.env` file. Refer to `.env.example` for the required settings.

4. Install backend dependencies:

```bash
cd backend
npm install
```

5. Start the backend using the start script defined in `backend/package.json`.

6. Install frontend dependencies:

```bash
cd frontend
npm install
```

7. Start the frontend using the development script defined in `frontend/package.json`.
